# 🚀 AlphaHunt - DeFi Degen Alpha Discovery Platform

Platform komunitas untuk menemukan alpha project DeFi, Memecoin, GameFi & Web3 sebelum pump! 💎

## 🌐 Live Demo

👉 https://alphahunt-kappa.vercel.app/


## ✨ Features

- 🔥 **Alpha Feed** - Discover early-stage projects
- 👥 **Voting System** - Upvote/downvote favorit kamu
- 🏆 **Leaderboard** - Top alpha hunters
- 💎 **Submit Alpha** - Share gem ke komunitas
- 📊 **Risk Score** - Automatic risk analysis
- ⛓️ **Multi-chain** - ETH, BSC, Solana, Base, Arbitrum, Polygon
- 📱 **Responsive** - Works on mobile & desktop

## 🛠️ Tech Stack

- HTML5 + Vanilla JavaScript
- TailwindCSS (via CDN)
- Pure browser-based (no install needed)
